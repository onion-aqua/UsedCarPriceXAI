# 第一周：数据→模型→解释运行报告

本轮用于验证链路，尚不是最终论文实验或异常检测准确率。

## 数据划分与编码

总计 119,662 条去重车源。train=71,797；validation=17,949；calibration=11,966；test=17,950。
同一 SKU 不跨集合。缺失值填补、One-Hot类别与原生类别词表均只在训练集拟合。Ridge 使用 One-Hot；LightGBM 将 pandas category 显式作为类别处理，不把品牌编号视为连续大小。
fuelType 和 power 并非独立原始列，但可从嵌套字段部分提取。fuelType缺失单列未知，不能假定为燃油；power单位kW，Ridge仅用训练中位数插补并添加缺失指示，LightGBM原生处理数值缺失。原始价格与log1p目标以相同划分对比，所有MAE/RMSE均还原到万元计算。

## 初步区间与解释

独立校准集构建90% split-conformal区间，测试集覆盖率 90.02%，平均区间宽度 7.3429 万元。其覆盖性质依赖可交换性，不意味着90%的异常识别准确率。
SHAP全局图随机使用 256 个测试样本，局部案例 jijkI14658457，加和校验最大误差 1.42e-14。
局部案例：上海，劳斯莱斯 / 库里南 / 6.7T 自动 四驱 4座。实际挂牌 690.00 万元，预测 1009.84 万元，90%区间 [852.08, 1196.78] 万元，初筛为疑似低价。这是按残差选取的极端示例，不能视为代表性样本。
SHAP输出尺度为 log(1 + 挂牌价/万元)，不可把对数SHAP值当作万元贡献。特征贡献解释模型预测，不能证明真实异常原因。
